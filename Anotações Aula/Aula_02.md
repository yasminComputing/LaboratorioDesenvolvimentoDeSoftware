## Java Swing
É uma biblioteca gráfica fornecida pela linguagem de programação Java para criar interfaces `gráficas de usuários (GUIs)`. Ele permite criar aplicativos com uma aparência e comportamento visual atraentes e interativos.

* Desvantagens:
    * Aparência e Experiência de Usuário
    * Desempenho
    * Falta de Recursos Modernos

Porém, o Swing é um método que facilmente poderemos compreender o desenvolvimento de software.
